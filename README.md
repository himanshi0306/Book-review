# Book-review
Server-side online book review application with secure JWT authentication. Users can register, log in, browse books, and post reviews.


## Features
- Browse books and view details
- User registration & login
- Add, update, delete reviews (authenticated)
- Async/Await handling for asynchronous operations
- REST API tested with Postman


## Installation
```bash
git clone <repo-url>
cd book-review-app
npm install
npm start
